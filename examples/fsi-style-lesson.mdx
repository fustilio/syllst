# Greetings and Introductions

## Basic Dialog

:::dialogue{id="greeting-basic" context="greeting" lang="th-TH"}

::turn{speaker="a" name="Speaker A" gender="masculine"}
สวัสดีครับ
# transcription: sa-wat-dii khrap
# en-US: Hello.
::

::turn{speaker="b" name="Speaker B" gender="masculine"}
สวัสดีครับ คุณสบายดีไหมครับ
# transcription: sa-wat-dii khrap, khun sa-baai-dii mai khrap
# en-US: Hello. How are you?
::

::turn{speaker="a"}
สบายดีครับ ขอบคุณครับ แล้วคุณล่ะครับ
# transcription: sa-baai-dii khrap, khop-khun khrap, laeo khun la khrap
# en-US: I'm fine, thank you. And you?
::

::turn{speaker="b"}
สบายดีครับ ขอบคุณครับ
# transcription: sa-baai-dii khrap, khop-khun khrap
# en-US: I'm fine, thank you.
::

::cultural-note
The Thai greeting สวัสดี (sa-wat-dii) is used for both hello and goodbye.
It is always followed by a polite particle: ครับ (khrap) for males, ค่ะ (kha) for females.
The physical gesture accompanying greetings is the ไหว้ (wai) — palms pressed together, raised to the chest or face.
::

:::

## Grammar Notes

:::grammar-rule{id="personal-pronouns" title="Personal Pronouns" difficulty="beginner"}

Thai personal pronouns vary by gender, formality, and social status.

### Common First-Person Pronouns

| Thai | Transcription | Usage |
|------|--------------|-------|
| ผม | phom | Male speaker (polite) |
| ดิฉัน | di-chan | Female speaker (polite) |
| ฉัน | chan | Informal (any gender) |

### Second-Person Pronoun

| Thai | Transcription | Usage |
|------|--------------|-------|
| คุณ | khun | You (polite, any gender) |

:::example{id="ex-pronoun-1" text="ผม สบายดี ครับ" transcription="phom sa-baai-dii khrap" translation="I'm fine. (male)" illustrates="personal-pronouns"}
Male speaker using ผม with masculine polite particle ครับ.
:::

:::example{id="ex-pronoun-2" text="ดิฉัน สบายดี ค่ะ" transcription="di-chan sa-baai-dii kha" translation="I'm fine. (female)" illustrates="personal-pronouns"}
Female speaker using ดิฉัน with feminine polite particle ค่ะ.
:::

:::

:::grammar-rule{id="polite-particles" title="Polite Particles ครับ/ค่ะ" difficulty="beginner"}

Thai sentences end with polite particles based on the speaker's gender:

- **ครับ** (khrap) — used by male speakers
- **ค่ะ** (kha, falling tone) — used by female speakers in statements
- **คะ** (kha, high tone) — used by female speakers in questions

:::example{id="ex-particle-statement" text="สวัสดีครับ" transcription="sa-wat-dii khrap" translation="Hello. (male speaking)" illustrates="polite-particles"}
Statement with male polite particle.
:::

:::example{id="ex-particle-question" text="สบายดีไหมคะ" transcription="sa-baai-dii mai kha" translation="How are you? (female asking)" illustrates="polite-particles"}
Question with female polite particle (high tone คะ).
:::

:::

:::grammar-rule{id="question-mai" title="Yes/No Questions with ไหม" difficulty="beginner"}

Add ไหม (mai) at the end of a statement to form a yes/no question.

:::example{id="ex-mai-statement" text="คุณ สบายดี" transcription="khun sa-baai-dii" translation="You are fine." illustrates="question-mai"}
Statement form.
:::

:::example{id="ex-mai-question" text="คุณ สบายดี ไหม" transcription="khun sa-baai-dii mai" translation="Are you fine?" illustrates="question-mai"}
Question form — ไหม added at end.
:::

:::

## Drills

### Expansion Drill

:::exercise{id="drill-expansion-1" type="pattern-practice" title="Greeting Expansion" skill="pattern-application" objectiveId="obj-polite-particles" data:drillType="expansion"}

**Question:** Build the greeting progressively, adding elements at each step.

- สบายดี → "be fine"
- สบายดี ครับ → "be fine (polite, male)"
- ผม สบายดี ครับ → "I'm fine (polite, male)"
- ผม สบายดี ครับ ขอบคุณ ครับ → "I'm fine, thank you (polite, male)"

**Answer:**
- สบายดี
- สบายดีครับ
- ผมสบายดีครับ
- ผมสบายดีครับ ขอบคุณครับ

**Explanation:** Expansion drills build sentence complexity progressively, reinforcing word order and polite particle placement.

:::

### Substitution Drill

:::exercise{id="drill-sub-1" type="pattern-practice" title="Pronoun Substitution" skill="pattern-application" objectiveId="obj-pronoun-usage" data:drillType="substitution" data:pattern="_____ สบายดี _____"}

**Question:** Replace the pronoun and polite particle following the pattern.

- Cue: ดิฉัน → ดิฉัน สบายดี ค่ะ
- Cue: เขา → เขา สบายดี ครับ
- Cue: ฉัน → ฉัน สบายดี

**Answer:**
- ดิฉัน สบายดี ค่ะ
- เขา สบายดี ครับ
- ฉัน สบายดี

**Explanation:** The polite particle changes based on the speaker. ดิฉัน takes ค่ะ (female), เขา (he/she) takes ครับ by default in this context, and informal ฉัน can omit the particle.

:::

### Transformation Drill

:::exercise{id="drill-transform-1" type="transformation" title="Statement to Question" skill="word-order" objectiveId="obj-question-formation" data:drillType="transformation"}

**Question:** Convert each statement into a yes/no question using ไหม.

- ผม สบายดี → Statement: "I'm fine."
- คุณ สบายดี → Statement: "You're fine."
- เขา สบายดี → Statement: "He/she is fine."

**Answer:**
- คุณ สบายดี ไหม
- คุณ สบายดี ไหม
- เขา สบายดี ไหม

**Explanation:** Add ไหม at the end. Note: in the first item, the subject changes from ผม (I) to คุณ (you) because you are now asking someone else.

:::

### Response Drill

:::exercise{id="drill-response-1" type="pattern-practice" title="Greeting Response" skill="situational-response" objectiveId="obj-greeting-dialogue" data:drillType="response"}

**Question:** Respond to each greeting appropriately (as a male speaker).

- Cue: สวัสดีครับ → Response: สวัสดีครับ
- Cue: คุณสบายดีไหมครับ → Response: สบายดีครับ ขอบคุณครับ
- Cue: แล้วคุณล่ะครับ → Response: สบายดีครับ ขอบคุณครับ

**Answer:**
- สวัสดีครับ
- สบายดีครับ ขอบคุณครับ
- สบายดีครับ ขอบคุณครับ

**Explanation:** Response drills practice appropriate conversational replies. Each cue requires a culturally appropriate response.

:::

## Exercises

:::exercise{id="exercise-roleplay-1" type="open-ended" title="Greeting Practice" skill="situational-response" objectiveId="obj-greeting-dialogue" data:drillType="communication"}

**Question:** Practice the following scenario with a partner:

You meet a Thai colleague at the office in the morning. Greet them, ask how they are, and respond when they ask you the same question. Use the appropriate polite particles for your gender.

**Explanation:** This is a free communicative exercise. Focus on natural flow, appropriate politeness levels, and correct particle usage.

:::

:::exercise{id="exercise-translate-1" type="translation" title="Translate to Thai" skill="word-production" objectiveId="obj-polite-particles"}

**Question:** Translate the following into Thai (as a female speaker):

1. Hello.
2. How are you?
3. I'm fine, thank you.

**Answer:**
- สวัสดีค่ะ
- คุณสบายดีไหมคะ
- ดิฉันสบายดีค่ะ ขอบคุณค่ะ

**Explanation:** Female speakers use ค่ะ for statements and คะ for questions.

:::
