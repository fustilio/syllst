This directory contains example syllabi and usage patterns for syllst.

## Contents

- **[TRANSFORMATION_EXAMPLES.md](./TRANSFORMATION_EXAMPLES.md)** - Examples of MDX to syllst AST transformations

## Adding Examples

To add a new example:

1. Create a new directory or markdown file
2. Include example MDX content and expected syllst AST output
3. Update this README with a link to your example
