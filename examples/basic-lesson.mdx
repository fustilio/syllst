# Basic Greetings

## Grammar

:::grammar-rule{id="greeting-pattern" title="Basic Greeting Pattern"}

The basic greeting pattern is simple and polite.

### Key Points

- Use formal greetings when addressing elders
- Informal greetings are for friends and peers

:::example{id="ex-greet-01" text="Hello, how are you?" translation="नमस्ते, आप कैसे हैं?" illustrates="greeting-pattern"}
A polite greeting.
:::

:::example{id="ex-greet-02" text="Good morning" translation="सुप्रभात" illustrates="greeting-pattern"}
Morning greeting.
:::

:::
