# Shopping Dialogue

## Dialogue

:::dialogue{id="shop-greeting" context="shopping" lang="en-US"}

::turn{speaker="customer" name="Alex" gender="neutral"}
Hello, do you have this in a larger size?
# transcription: hə-ˈlō du yu hav ðɪs ɪn ə ˈlɑːr-dʒər saɪz
::

::turn{speaker="shopkeeper" name="Sam" gender="neutral"}
Yes, let me check for you.
# transcription: yes let mi ˈtʃek fɔːr yu
::

::turn{speaker="customer"}
Thank you!
# transcription: θæŋk yu
::

::cultural-note
In many cultures, it's polite to greet shopkeepers before asking for help.
::

:::
